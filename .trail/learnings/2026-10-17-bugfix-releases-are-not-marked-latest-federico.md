## Decided
For a bugfix point release (6.2.1, 6.2.2, 6.1.9), do not set the GitHub release as latest. Instead add a pop-up note on top of the major release (e.g. 6.2.0), as done for 6.1.0 and 6.2.0.
The user asked to record this in AGENTS.md so they stop repeating it. Check how past releases were done before cutting a new one.
